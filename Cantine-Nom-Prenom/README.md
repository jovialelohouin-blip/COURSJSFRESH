# Gestion de cantine
# Description
Projet réalisé en JavaScript dans le cadre de la formation DFS. Il permet de gérer les commandes de repas d'une cantine et de calculer le montant à payer.
# Menu
- Attiéké-poisson : 1 500 FCFA
- Riz-poulet : 2 000 FCFA
- Alloco-œuf : 1 000 FCFA
# Fonctionnalités
- Choix du plat avec switch.
- Calcul du total avec une fonction.
- Affichage des portions avec une boucle for.
- Calcul de la monnaie ou du montant manquant avec if/else.
# Technologies
JavaScript, VS Code et Git.
